# 06 — 生命周期管理（Lifecycle Management）

## 1. 阶段概述

生命周期管理阶段是 IPD 流程的最后一个阶段，核心任务是：
- 持续维护与支持已发布产品
- 收集用户反馈，驱动产品演进
- 规划产品路线图
- 管理产品退役

**决策评审点**：生命周期决策评审（EOL DCP）

## 4. 性能监控

### 4.1 性能基准

| 基准 | 指标 | 目标 | 监控频率 |
|------|------|------|---------|
| CoreMark | 分数 | 持续 | 每次提交 |
| Dhrystone | DMIPS | 持续 | 每次提交 |
| SPECint | 分数 | 不降低 | 每周 |
| SPECfp | 分数 | 不降低 | 每周 |
| 启动时间 | 秒 | 不增加 | 每日 |

### 4.2 性能回归检测

```yaml
# CI 性能回归配置
performance_regression:
  triggers:
    - schedule: "0 0 * * *"  # 每天
  benchmarks:
    - name: coremark
      threshold: 5%  # 允许 5% 波动
    - name: dhrystone
      threshold: 5%
    - name: specint
      threshold: 3%
  actions:
    - notify: xiangshan-dev@googlegroups.com
    - create_issue: true
```

## 7. 退役管理

### 7.1 退役标准

| 条件 | 说明 |
|------|------|
| 技术落后 | 无法满足新应用需求 |
| 维护成本 | 维护成本超过收益 |
| 替代产品 | 有更好的替代方案 |
| 生态变化 | 工具链/生态不再支持 |

### 7.2 退役流程

```
退役流程：
1. 退役评估
2. 用户通知 (提前 6 个月)
3. 维护模式切换
4. 文档归档
5. 代码冻结
6. 正式发布退役公告
7. 停止支持
```

### 7.3 退役公告模板

```markdown
# XiangShan Kunminghu V1 退役公告

## 发布日期
2026-12-31

## 概述
经过慎重考虑，我们决定停止对昆明湖 V1 版本的维护和支持。

## 时间安排
- 2026-06-30: 停止新功能开发
- 2026-09-30: 停止 Bug 修复
- 2026-12-31: 正式退役

## 替代方案
建议用户迁移至昆明湖 V2 版本，以获得更好的性能和功能。

## 迁移指南
[迁移至昆明湖 V2](./migration-guide.md)

## 致谢
感谢所有支持和贡献昆明湖 V1 的用户和开发者。
```
